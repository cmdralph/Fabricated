# Popular Fabric mods CI loads together (informational), by Modrinth project slug. Each one's newest Fabric build
# for the Minecraft version is used, with its required dependencies; a mod without such a build is left out.
# Mods that replace the renderer (Sodium, Iris) are not listed: their Fabric builds can't run on NeoForge, and CI
# runs their NeoForge builds next to Fabric API separately.
# Nor are jars that are NeoForge mods too: NeoForge loads those itself (Zoomify's "universal" jar, which then needs
# Kotlin for Forge). Nor malilib, with Tweakeroo and MiniHUD: the compatibility plan refuses them until a run of their
# own verifies them on the map Fabricated restores (PIP-1, CORPUS-13). Nor WTHIT's Fabric build, which refuses NeoForge.
